# Public Boundary

This repository is intentionally non-operational.

Publicly shareable:
- project mission;
- governance and safety principles;
- high-level architecture concepts;
- presentation materials that have been explicitly reviewed for publication.

Not publicly shareable:
- private source code;
- sensitive datasets or case material;
- credentials or infrastructure details;
- operational collection procedures;
- restricted investigative capabilities;
- personal data or protected-subject records.

If a proposed update crosses this boundary, it should not be published here.
